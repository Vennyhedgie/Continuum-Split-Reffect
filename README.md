# Continuum-Split-Reffect
A more visible UI element for Mesmer's Chronomancer Elite Specialization

<img width="821" height="219" alt="image" src="https://github.com/user-attachments/assets/1ed903f7-2094-4dc6-b3f0-e5b974032b7a" />

Adds a bar to track Continuum Split duration.


# How to use
Simply download the pack file into your reffect packs folder like so:

<img width="700" height="352" alt="image" src="https://github.com/user-attachments/assets/6ccb0c7e-91a2-492b-a190-acf9e11e34e1" />

Then, return to reffect ingame and refresh packs.

# Notes

This effect is made with Normal interface size. If you use a different one, you can resize all the elements at once by right-clicking on the pack and selecting resize. Alternatively, you can move the pack's position on screen if needed, though it should be aligned by default.
